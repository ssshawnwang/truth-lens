# Sprint 1

**Goal:** ship Version 1, Core Exploration, as a clickable prototype with sample data.

## Delivered

- Search by keyword, with a no-results state
- Viewpoint rail with short titles; select one to explore
- AI summary per viewpoint with numbered citations; "All summaries" reading mode
- Source list per viewpoint with title, publisher, date, excerpt, and original link
- Unavailable-source and missing-date states
- Uncertainty notices: only one viewpoint found, limited evidence
